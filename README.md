# Actividad Tributaria

Proyecto web estático para la gestión y consulta de información tributaria.

## Descripción

Este repositorio contiene una aplicación desarrollada en HTML que presenta una interfaz para consultar y visualizar información relacionada con actividades tributarias. Está pensado como una solución sencilla, ligera y fácil de ejecutar sin dependencias adicionales.

## Tecnologías

- HTML
- CSS (si se incluye en el proyecto)
- JavaScript (si se incluye en el proyecto)

## Cómo ejecutar

1. Descarga o clona este repositorio.
2. Abre el archivo `index.html` en tu navegador.
3. Si tu proyecto requiere un servidor local, puedes usar uno simple como Live Server o Python:

```bash
python -m http.server 8000
```

Luego abre en el navegador:

```text
http://localhost:8000
```

## Objetivo

Proporcionar una vista accesible y funcional para la consulta de información relacionada con la actividad tributaria, con una experiencia simple y directa para el usuario.
